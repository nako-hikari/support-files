# Using NPC to do setup instantly
## like summoning a few tagged entities, placing command block tower(empty), or others

taking advantage of npc capabilities to do boring setup

here's how you do it

### 1
summon an npc using
``` 
/summon npc
``` 
![Image](https://raw.githubusercontent.com/nako-hikari/support-files/main/npc-setup/npc-setup-tut-1.png)

### 2
interact with the npc by right click or long press
![Image](https://raw.githubusercontent.com/nako-hikari/support-files/main/npc-setup/npc-setup-tut-2.png)

### 3
press the "advance setting" button 
![Image](https://raw.githubusercontent.com/nako-hikari/support-files/main/npc-setup/npc-setup-tut-3.png)

### 4
press the "add command" button once
![Image](https://raw.githubusercontent.com/nako-hikari/support-files/main/npc-setup/npc-setup-tut-4.png)

### 5
paste the multiple line setup command on the top box
and activate "button mode"
![Image](https://raw.githubusercontent.com/nako-hikari/support-files/main/npc-setup/npc-setup-tut-5.png)

### 6
close the current tab
![Image](https://raw.githubusercontent.com/nako-hikari/support-files/main/npc-setup/npc-setup-tut-6.png)

### 7
press the "edit dialogue" button to open the dialogue tab
![Image](https://raw.githubusercontent.com/nako-hikari/support-files/main/npc-setup/npc-setup-tut-7.png)

### 8
press the empty button on the bottom left corner of the ui
![Image](https://raw.githubusercontent.com/nako-hikari/support-files/main/npc-setup/npc-setup-tut-8.png)

### 9
now you're done :)
the setup is now complete
![Image](https://raw.githubusercontent.com/nako-hikari/support-files/main/npc-setup/npc-setup-tut-9.png)
